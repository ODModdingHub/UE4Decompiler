# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 2.x | Yes |
| < 2.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in UE4Decompiler (such as a path traversal flaw or memory corruption in container handling), please do not open a public issue.

Instead, please email the maintainers or report it privately through GitHub Security Advisories.
All reports will be acknowledged within 48 hours and investigated promptly.
